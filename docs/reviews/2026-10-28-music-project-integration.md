## 接入功能

| 功能 | 接入情况 |
|---|---|
| 网易云 NCM | 沿用 VERT 有界流式读取，增加封面写入；标题、歌手、专辑在保留元数据时写入 |
| QQ 音乐 | 接入 QMC v1 静态密钥、v2 Map/RC4、内嵌 EKey；无内嵌密钥时可手动提供 EKey 或选择本地 SQLite 密钥库 |
| 酷狗 KGM/KGMA/VPR | 接入公开公钥和相位变换；增加版本与偏移检查 |
| 酷我 KWM | 接入旧版密钥恢复；无可验证候选时拒绝，不输出未知内容 |
| 输出 | 原始音频还原及既有 MP3/FLAC/M4A/WAV/OGG/Opus 等转码路线；保留原始编码和选目标转码在界面分别说明 |
| 批量 | 文件夹递归添加，跳过隐藏项和符号链接，最多 1000 个文件；可选逐个或同时 2 项，停止后不启动后续项 |
| ZIP | 打包已完成的文件结果，同名自动编号，中文文件名写入标准 UTF-8 标记；最大总大小 2 GB |
| 预览 | 输出音频显示歌曲标题、歌手、专辑、时长、采样率和可读取的封面；试听使用“系统打开” |
| 安全保存 | 沿用原有同名编号和源文件保护。添加队列可先核对格式再开始，相当于 GUI 计划预览；不引入 CLI 的强制覆盖或本地 Web 服务 |

EKey 和密钥库路径仅保留于当前会话，不进入持久设置、预设或任务历史。密钥库以只读 URI 打开，检查表结构并限制查询量；密钥经私有临时请求文件交给 Python，不放进进程参数。不会自动搜索客户端账户或读取未选择的密钥库。

## 接入中修正的问题

1. 上游 KWM 无有效候选时仍输出猜测结果，现改为明确拒绝未知音频。
2. 增加 KGM 偏移/版本校验和文件大小限制；每次解码独立进程，避免跨歌曲相位表缓存累积。
3. 非 NCM 沿用音频内原有标签，避免空元数据文件覆盖已有标题。
4. 只移除经过验证的非音频零填充，保留 M4A box 长度中的前导零。实际对比发现 KWM 前导填充影响重封装后的 gapless 采样，规范化后 PCM 对比恢复一致。
5. MP3 封面写入保留已有标签，写入失败明确提示；封面在临时副本写入成功后原子替换，失败不破坏已转换音频。
6. 实测 macOS ditto 生成的中文 ZIP 未设置 UTF-8 标记，跨平台读取乱码。新批量 ZIP 使用 Python ZIP 写入，已验证中文名称、同名编号和各文件内容。

- 37 项生产函数调用：34 项转换成功并实际解码，3 项无外部密钥的 QQ 样本按预期拒绝。覆盖 NCM、QMC v1、QTag Map/RC4、STag 外部密钥、KGM、KWM、复合扩展名、魔数识别和保留元数据开关。

- 使用用户此前授权的真实桌面 NCM，验证原始还原和 FLAC 输出封面，不修改原件。
- 43 项 Python、180 项前端单元、26 项浏览器 E2E 通过；Rust 常规和真实 ZIP 集成测试通过。ZIP 集成检查实际读取中文名称、同名文件的不同内容、CRC、无 AppleDouble 及路径穿越拒绝。
- 前端构建、ESLint、macOS 应用包构建通过。E2E 使用受控 Tauri 接口模拟；真实转换、文件内容检查及安装版测试分别记录。

## 范围与限制

KGG v5 仍不支持；新版 QQ 无内嵌 EKey 的文件必须提供匹配密钥。KWM 仅覆盖旧版，KGM 的变体兼容性仍需真实样本扩大验证。本轮除网易云外主要使用自建合成文件，不能把上游 README 的“全部”当作本应用已覆盖所有平台版本的承诺。

保留流式 NCM 的 8 GB 上限；其他整段读取的加密音乐限 256 MB；密钥库限 128 MB，封面限 8 MB，预览限 128 MB。当前主要容器嗅探为 MP3/FLAC/M4A/WAV/OGG；某些旧扩展名若内部实际为 APE、ASF/WMA 等未覆盖容器，会明确拒绝，不作为已验证可用格式宣传。封面嵌入覆盖 MP3/FLAC/M4A，其他目标会提示；不承诺所有特殊标签完整保留。

上游 CLI/Web 的宿主形式、强制覆盖、客户端降级和密钥提取操作不移植。使用本应用已有队列、保存和取消机制，不改变用户指定的默认保存目录。
