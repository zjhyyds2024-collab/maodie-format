# 猫头图标替换

用户于 2026-10-28 指定将所附橘猫照片的头部作为「耄耋格式」软件图标。

使用内置 image_gen 编辑工具提取猫头、移除背景和身体，并修复低分辨率细节；母版含透明通道，见 `assets/maodie-cat-head.png`。提示词摘要与再生成说明见 `assets/README.md`。没有改成卡通风格或增加文字。

以 Tauri icon 工具生成 PNG / ICNS / ICO，替换 `src-tauri/icons/` 的现有图标。侧栏与 favicon 同步使用 `public/app-icon.png`。原始 VERT Enhanced 应用保留，不在此次图标替换范围内。

验证：透明通道与 128px 外观已检查；6 项导航及布局测试通过，ESLint、前端构建通过。应用重新构建与 ad-hoc 签名后安装到 `/Applications/耄耋格式.app`。旧图标的耄耋格式版本备份在 `outputs/maodie-format-1.7.0/耄耋格式-before-cat-icon.app`。该备份使用相同应用标识，仅供回退，不建议与新版同时运行。

本轮仅本地修改，未上传 GitHub。
