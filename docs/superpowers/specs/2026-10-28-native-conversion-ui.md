# VERT Enhanced 原生工作台改进

用户要求继续测试，并查找同类好用 UI 参考改进。延续此前明确的 macOS 原生风格和主页/转换页合并方向。参考的是公开截图中的工作流和层级，不复制商标、素材或专有代码。

## 参考与取舍

- Permute 4：https://software.charliemonroe.net/permute/ ，官方主窗口截图显示文件队列、每组输出格式、逐项进度和底部总状态。借鉴文件与结果优先的组织方式。其玻璃与多色大缩略图不适合本应用的混合文档队列。
- Clop：https://lowtechguys.com/clop/ ，官方批量窗口展示紧凑列表，说明中按媒体类型配置参数。借鉴紧凑任务行及局部结果反馈。
- Pimosa：https://pimosa.app/ ，多工具聚合，适合工具库导航；转换主界面继续保持直接添加文件，不恢复分类首页。
- ImageOptim：https://imageoptim.com/mac ，拖放和结果列表适合轻量工具，但参数能力比本应用少，不能整套照搬。

选用紧凑队列加可折叠检查器。相比缩略图网格，这一方案能同时容纳图片、音频、视频、Office 和错误长文本；相比纯表格，窄窗口仍能换行显示操作。

## 视觉与布局

颜色：画布 #F5F5F7，内容 #FFFFFF，侧栏 #EBEBED，文字 #1D1D1F，次级文字 #6E6E73，强调 #24834B；深色分别使用现有 30/38 灰阶。字体 -apple-system 为主，标题 20，正文 13，说明 11–12。左对齐，数字使用等宽数字；不添加展示字体或营销标语。

```
侧栏 176 | 转换工作台 + 说明         [参数栏开关]
         | 文件数 / 总体状态
         | 添加区域                  | 常用预设
         | 图标 文件名 目标 状态 操作 | 参数表单
         | 可选择的错误和保存路径     | 输出说明
         | 固定底部队列操作及保存目录 |
```

文件行有类型图标、可读状态文字和输出格式；完成不整行铺绿色。主操作只强调批量开始按钮，逐项保存/预览使用普通按钮。预设为紧凑行，选中态有边框/淡底色；保留独立编辑按钮。检查器开关显示展开状态，不改变预设或队列。右侧补充全局采样率入口，和设置页保持同一数据源，预设覆盖规则写明。

## 功能与验证

复用原转换、保存、预设和历史数据接口。不得为了展示伪造文件缩略图、转换成功或压缩率。检查混合文件队列、失败后的批量继续、重试、取消、处理中禁用、自动保存失败提示、同名结果保留；在 800/1200 宽度、深浅主题检查滚动与按钮可见性。桌面安装版用合成文件实测。

本轮不新增转换引擎，不修改已验证的采样率和文档转换算法。若测试发现相关交互缺陷，单独记录触发方式与修复验证。

## 视觉自查与测试补充

初稿的预设和工具栏仍偏高，已降低行高；宽窗口改成两栏各自滚动，避免查看参数时丢失任务上下文。仅用系统字体，不引入竞品大图或玻璃背景。增加 ⌘O 文件选择快捷键，模式对话框内拦截。

真实损坏图片测试暴露出错误文本过于技术化。最终为已识别的损坏内容增加恢复建议和可展开的诊断；其他错误保留原文，避免错误归因。有完成文件时明确按钮仅转换未完成项。
