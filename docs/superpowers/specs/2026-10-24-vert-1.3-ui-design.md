# VERT Enhanced 1.3 界面与工作流设计

状态：用户于 2026-10-24 回复“继续”，已确认本书面方案。

## 目标与选择

在已有 1.2 转换能力上完成同一条工作流：选择用途 → 添加文件 → 调整参数 → 转换 → 检查结果 → 保存 → 从历史重新使用。

选择方案：直接改进本地 React/Tailwind 界面并复用现有 Rust 转换命令。Figma/MagicPath 设计后再实现会增加外部账号和交接步骤；仅做配色调整无法改善任务操作。推荐直接在现有项目落地本方案，无需购买设计插件。

## 界面布局

保留 VERT 绿色品牌，使用中性浅灰背景、白色面板、统一圆角和清晰的字号层次；深色模式提供对应颜色。

宽屏采用左侧导航：开始、转换队列、工具箱、任务记录、设置。右侧为当前工作区。窄窗口改用紧凑导航，转换设置与预览顺序排列，避免横向滚动。所有图标操作提供名称、键盘焦点和禁用状态。

首页由标题、文件拖放区、常用预设、工具箱入口和最近任务组成。添加文件后进入转换队列。转换页中央显示文件与状态，右侧显示用途预设、输出目录和参数；顶部显示完成数量与批量开始/停止。任务正在运行时参数锁定，状态使用真实阶段文案；未知总进度时显示不确定进度。

工具箱保留现有 PDF/OCR/ZIP 操作与运行时导航锁定，统一布局和样式。历史入口显示最近记录数量。

## 常用预设

首批提供“原参数”“图片转 JPG”“图片转 WebP”“音频转 MP3”“视频转 MP4”“文档转 PDF”。每项只使用已经实现的格式与参数：图片质量、音频码率/采样率、元数据保留。视频预设只设置输出格式，不承诺指定体积、分辨率或社交平台兼容性。

选择预设不会直接启动任务。只作用于匹配类别且目标格式在 allowedFormats 中的待处理文件；完成、运行中的文件不变。显示应用数量与不适用数量，允许恢复默认参数。添加新文件时应用当前预设，最终可用格式仍以引擎检查为准。

现有全局设置作为默认参数，预设作为本次队列参数覆盖；执行任务时保存参数快照，历史重试恢复该快照，避免后续设置变化改变旧任务含义。

## 结果预览

转换成功后提供“预览”入口。普通位图支持原图/结果切换和并排查看，显示输入/输出体积与变化比例；失败的图片解码显示明确提示。RAW 等无法直接显示的源格式只预览可显示的结果。

TXT/MD/JSON/CSV/XML/YAML/LOG 结果提供可选择复制的纯文本预览，最多读取 256 KiB，截断时说明。HTML 与 SVG 不执行或注入 DOM；不将未知文件直接作为网页加载。

PDF 首版显示第一页缩略图、页数与文件大小，复用 PDFKit 工具生成缩略图；提供在系统默认应用打开完整文件的操作。音视频及 Office 文件提供文件信息和系统打开，不承诺内嵌播放或排版预览。文件夹结果提供 Finder 入口。

预览命令只读取普通文件；限制读取大小和缩略图尺寸。切换文件、关闭预览时清理临时 URL 与异步请求状态，防止旧任务内容覆盖新选择。缺失、已移动或无权限文件显示可恢复的错误。

## 任务记录

添加独立任务记录存储，最多保留最近 100 次实际执行记录，跨重启保留。记录开始/结束时间、来源名称与路径、目标格式或工具操作、参数快照、状态、输出路径、保存路径、输出大小及警告摘要。完成、失败、取消均记录；队列中尚未执行的文件不算历史。

历史支持全部/成功/失败/取消筛选、名称搜索、打开结果、Finder 定位、重新加入队列、删除单条和清空记录。重试需要重新检查源文件及可用格式，不自动开始转换。涉及 PDF 密码的工具不保存密码；再次执行时返回工具箱重新输入必要参数。

工具箱任务通过共同的记录入口写入历史，但仍沿用现有执行模型。普通任务的终态由单一完成入口提交，避免 React 重渲染、重试或保存动作重复创建记录。保存成功后更新对应记录的最终路径。

历史记录仅存储元数据，不把转换文件内容存入浏览器存储。删除历史不删除源文件或结果。未手动保存的结果标记为临时文件，重启后文件不存在时提示不可用；不能把临时结果冒充永久保存。

## 实现边界

新增 presets 模块定义可选用途、类别匹配及参数覆盖；新增 history store 管理版本化持久化与筛选；新增共用任务执行/记录适配层，统一队列和工具箱的状态与错误记录；新增 Preview 组件和有限读取/缩略图/系统打开命令。保留现有默认设置数据及语言选择。

本版聚焦界面与工作流。OFD、MOBI、扫描表格识别、Finder 扩展、自动监控文件夹留在后续独立版本，首页不显示为已支持功能。

## 验收

1. 在浅色、深色及 800/1200 像素宽窗口检查首页、队列、工具箱、历史与设置；常用操作无横向溢出。
2. 混合类别队列验证预设应用、跳过、格式不支持、参数锁定与新加入文件；真实转换产物可打开。
3. 检查历史参数快照、重复执行、跨重启、100 条裁剪、清空、缺失文件和保存路径同步；PDF 密码不进入持久化数据。
4. 用真实图片、纯文本、PDF 和不支持预览的文件验证预览；检查文本截断、HTML/SVG 安全展示和快速切换预览。
5. 回归批量部分失败、取消、工具箱记录及同名文件保存。运行必要单元测试、现有 E2E、lint、TypeScript/Vite 构建、Rust 检查，并在实际 macOS 应用验收关键流程。
6. 完成后构建 1.3.0、签名校验并更新 /Applications/VERT Enhanced.app；保留原 VERT Desktop.app，提供应用包与更新说明。
