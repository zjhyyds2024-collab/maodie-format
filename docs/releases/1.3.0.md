# VERT Enhanced 1.3.0

已在本机更新 /Applications/VERT Enhanced.app。原 VERT Desktop.app 保留。

## 新版界面

左侧导航统一管理主页、转换队列、工具箱、任务记录和设置。宽窗口转换页提供右侧参数面板，窄窗口自动排列；支持深浅色主题。

## 常用预设

图片转 JPG / WebP、音频转 MP3、视频转 MP4、文档转 PDF。预设只影响匹配类别、允许目标格式的待处理文件，不会自动执行。可以在队列中更改目标格式；默认参数用于没有预设覆盖的文件。

## 预览

成功结果可直接预览。图片支持原图/结果并排查看和体积比较；PDF 显示首页及页数；TXT/MD/JSON/XML/YAML/CSV/HTML 等显示纯文本，最多读取 256 KiB。HTML 和 SVG 不执行脚本。图片预览使用最长边 1400 像素的缩略图，动图仅首帧，不能代替全尺寸画质验收。大于 128 MiB 的图片/PDF 及其他格式请使用系统应用或 Finder 查看。

## 任务记录

最近 100 次实际执行的普通转换和工具箱任务保存在本机。支持搜索、按状态筛选、预览、Finder 定位和重新加入；重试会恢复参数但不会自动开始。PDF 密码不记录，解密重试需重新输入。删除记录不删除文件。

记录只保存路径与元数据。没有保存的临时结果会在退出应用后清理；要保留结果，请先保存。文件移动或删除后，历史记录无法恢复其内容。

## 验证

- 前端单元测试 164 项、浏览器 E2E 13 项通过。
- Rust 常规单元测试 5 项通过，含文本预览读取上限；Swift 真实三页 PDF 缩略图返回页数正确。
- 已在实际安装应用验证中文 PNG → WebP、图片并排预览、手动保存、历史同步、图片合并 PDF 和 PDF 首页预览；应用重启后已保存结果仍可预览。
- TypeScript/Vite 构建、ESLint、Rustfmt、本地签名校验通过。

本版重点是界面和操作流程；OFD、MOBI、扫描表格转 Excel 仍未提供。
应用包适用于这台 Mac 已配置的本地引擎；迁移其他 Mac 仍需按使用说明安装引擎。
