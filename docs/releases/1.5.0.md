# VERT Enhanced 1.5.0

## 页面分工

- 首页改为工作总览：开始/继续转换、队列概况和最近任务。不再重复上传区和预设，也没有重新加入原先移除的类别格子或工具箱跳转卡片。
- 转换页集中处理添加文件、常用预设、参数、队列、预览和保存。空队列仍可直接进入。

## 工具箱

参考 PDF24 的工具选择方式，改为支持搜索和分类的工具大厅，现有工具以卡片展示。分类包括所有工具、PDF 整理、转换与 OCR、压缩与解压。

点击卡片进入该工具独立操作页：选择文件 → 设置选项 → 预览/保存。支持返回工具大厅、工具直达链接与历史重试；运行期间保留原有取消、真实阶段进度及默认保存目录。

## 四项新 PDF 功能

- 旋转页面：全部或指定页面顺时针旋转 90° / 180° / 270°。
- 提取页面：按指定页码另存一个 PDF，如 1-3,5。
- 删除页面：从副本移除指定页码，不允许删除全部页面。
- 页面重排：输入完整的新顺序，如 3,1,2；每页需出现且仅出现一次。

这些功能支持 1–10000 页 PDF，拒绝越界和重复页码，密码 PDF 需先解密。原文件不改写；涉及书签、表单、附件或注释时请按结果提示核对。旋转参数会随任务历史保存并在重试时恢复。

本版仅参考交互形式，所有用户文件仍在本机处理，没有上传至 PDF24。
