# VERT Enhanced 1.4.0

按本次六项要求调整：

1. 转换页没有文件时也可进入，显示拖放入口和预设；移除全部文件后仍留在转换页。
2. 工具箱移除底部六个本地组件信息格子。
3. 压缩工具新增创建 7Z、TAR、TAR.GZ、TAR.BZ2、TAR.XZ，保留 ZIP；可解压 ZIP、7Z、RAR、TAR、GZ、BZ2、XZ（含 TGZ/TBZ2/TXZ）。RAR 只支持解压。加密、分卷及部分特殊变体暂不支持；压缩工具只打包普通文件。新格式每次最多 10000 项、文件总量/解压内容最多 2 GiB；拒绝越界路径、链接与特殊文件，结果先进入独立任务目录。
4. 设置页“关于软件”改为按钮，点击才打开介绍窗口。
5. 设置页新增“反馈与建议”，接收邮箱为 zjhyyds2024@gmail.com。填写后打开默认邮件应用的草稿，由用户确认发送；不会自动附带文件路径或历史记录。没有可用邮件应用时可手动发送到该邮箱。
6. 设置页新增“默认保存位置”，支持选择目录、一键使用系统下载文件夹，以及恢复手动保存。目录会记忆，应用于普通转换/工具箱自动保存与单个结果的另存对话框；同名自动保存文件编号保留。
