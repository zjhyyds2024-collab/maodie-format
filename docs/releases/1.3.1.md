# VERT Enhanced 1.3.1

按本次四项要求调整：

1. 首页移除 PDF / OCR / ZIP 工具箱跳转卡片。侧栏工具箱保留。
2. 首页移除图片、音频、视频、文档四个格式类别卡片；兼容性说明移入设置页。
3. 设置页新增“关于软件”：功能介绍、使用方法、本地处理与保存说明、兼容性及原作者/许可。
4. 常用预设支持编辑：点击卡片右上角铅笔，可修改名称、输出格式、图片质量或音频码率/采样率。保存后重启仍保留，也可恢复默认。默认参数仍由设置页修改。

修改当前选中的预设时，会同步适用的待处理文件；不支持目标格式的文件跳过。已完成任务和历史参数不会被改写。取消编辑不会保存。

验证：170 项单元测试、14 项浏览器 E2E、TypeScript/Vite 构建和 ESLint 通过。

已安装至 /Applications/VERT Enhanced.app。原 VERT Desktop.app 保留。应用仍使用本机已配置的转换引擎；未保存的临时结果仍会在退出时清理。
